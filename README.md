# programming-easy
This repository contains the Easy-level programming tasks completed for the Programming domain selection.

1. Expense Tracker
A command-line Java program that allows users to:

Add expenses with amount, category and description
View all recorded expenses
Calculate total spending
Calculate spending by category
Identify the category with the highest spending
Concepts Used
Variables
Input and output
Loops
Conditions
ArrayList
HashMap
Classes and objects

2. Password Strength Checker
A command-line Java program that checks the strength of a password based on:

Minimum length of 8 characters
Uppercase letter
Lowercase letter
Number
Special character
The program displays the requirements satisfied and provides an overall strength rating of Weak, Medium or Strong.

Concepts Used
Strings
Conditions
Loops
Functions
Boolean variables
Character methods
Language
Java
